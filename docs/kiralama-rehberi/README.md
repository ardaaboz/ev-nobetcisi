# Kiralama Rehberi

Nöbetçi sistemin yanında, ev bulma sürecinin insan tarafı için hazırlanmış notlar.

| Döküman | Ne zaman lazım |
|---|---|
| [Ev gezerken sorular](ev-gezerken-sorular.md) | Randevu aldıktan sonra, eve giderken |
| [Sözleşme kontrol listesi](sozlesme-kontrol-listesi.md) | Anlaşma aşamasında, imzadan önce |
| [Beli karton notu](beli-karton-notu.md) | Ev gezildikten sonra, sözleşme konuşulurken |
| [Semt ve ulaşım](semt-ulasim.md) | İlan değerlendirirken |

## Sıralama

1. Sistem ilanı bulur → Telegram'a düşer
2. Hazır Sırpça taslağı gönderirsin (vergi/beli karton **geçmez**)
3. Randevu alırsın → [ev gezerken sorular](ev-gezerken-sorular.md)
4. Olumluysa → [beli karton](beli-karton-notu.md) açılır
5. Anlaşma → [sözleşme kontrol listesi](sozlesme-kontrol-listesi.md)

Bu sıra önemli: idari konuları erken açmak, ilanların çoğunda cevapsız
kalmana yol açar. Elemeyi ev sahibi değil sen yap.
